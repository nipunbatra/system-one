Read, don't write

An ordinary chat LLM, with no training for this and nothing added, answers typed questions in one forward pass. You will see how the question is written for the model, the scores it produces, and the few scores we read.

2How the question is encoded

There is no special input format inside the model. The question and its allowed answers are written as plain text, each option gets a letter, and the text ends exactly where the answer would start.


      

    


    

      
3One forward pass: a score for every token

      
The model gives one score to each of the  tokens it knows, for "what comes next". These are the twelve most likely. A chat model would now pick one and keep writing.

6A second design: score each option on its own

      
Above, the options competed inside one prompt. Here the same yes or no question is asked once per option, "does this option fit?", and the yes probabilities are compared. One scorer is reused for every option, which is the idea behind a shared decision head.

      

      

      
This took one pass per option. A trained decision model gets all of these scores in a single pass, from the vector at each option's position. That step needs training, so an off-the-shelf model cannot show it.
